Privacy

Last updated August 17, 2026

What we collect

When you submit the access request form, we receive the name, email address, optional company, and message you type. The website sets no cookies and runs no analytics or tracking scripts.

How it is used

Your submission is stored so DeepUbuntu Labs can review it and reply to you about Fraeno. It is not sold, shared, or added to any marketing list.

Where it lives

Submissions are transmitted over HTTPS and stored with Cloudflare so we can keep track of the conversation. A confirmation is sent to the email address you provide.

Product updates

If you tick the updates box, we may send you occasional Fraeno product news. We never email marketing to anyone who has not opted in, and one message to thabhelo@deepubuntu.com removes you from the list.

Fraeno installations

When you install the Fraeno GitHub App, we store the installation ID, GitHub account, connected repository status, and basic check activity. We use this information to provide access, keep checks working, and understand whether Fraeno is being used. We do not store repository source code in this customer record.

Your choices

To have your messages deleted, email thabhelo@deepubuntu.com and we will remove them.
