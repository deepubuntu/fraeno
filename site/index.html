The failure ordinary dependency bots miss

The build passed. The robot stopped communicating.

In Fraeno's live ROS 2 fixture, the candidate still builds after an update. But its sensor publisher changes to best effort while the controller still requires reliable delivery. The controller receives nothing, the command topic falls silent, and diagnostics worsen.

Fraeno observes the running graph and blocks the change.
