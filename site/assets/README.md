# Site assets

`fraeno-robot-arm.webp` is an original unbranded visual generated for Fraeno.

`robot-system-loop.mp4` and `robot-system-poster.webp` are silent, unbranded crops of a
robotics motion graphic supplied by the project owner. The crop removes the source headline and
call to action so the media remains a supporting system visual.
